## Complements

### Ce que cette fiche ne prouve pas (D-053, D-057)
Pas de visite guidee par tranche en mode autonome, et pas de robot de navigateur (D-027). Les tests prouvent le HTML rendu par le serveur, les routes par appel direct, et le choix du message de refus par la fonction pure `joinErrorMessage`.

**Rien de ce qui suit n'est exerce automatiquement** : une faute ici garderait la suite verte jusqu'a la visite guidee faite apres la fusion de 004.
- le formulaire « rejoindre » appelle bien `/api/household/join` avec la cle `code` ;
- le message d'erreur s'affiche a l'ecran, et la redirection vers `/household` a lieu apres le succes ;
- le bouton « Regenerer le code » appelle la route, puis `router.refresh()` montre le nouveau code.

### Points a verifier a la visite guidee
1. Sur `/no-household`, un code valide saisi avec un tiret mene a `/household`.
2. Un code inconnu affiche « Ce code n'est pas valide. Verifiez-le et reessayez. », sans quitter la page.
3. Un code contenant `U` affiche le meme message (422).
4. Un foyer de 10 membres affiche « Ce foyer est complet : il compte deja 10 membres. ».
5. La responsable voit le code ; « Regenerer le code » le remplace aussitot a l'ecran.
6. Un membre ne voit ni le code ni le bouton.
